# How to Run the Kidex Game Website

This document explains how to run the Kidex Game website locally and how it is deployed on GitHub Pages.

## Running Locally

1. Clone the repository:

```bash
git clone https://github.com/sumitrao9/MVP-KID-GAME.git
```

2. Navigate to the project directory:

```bash
cd MVP-KID-GAME/Game
```

3. Open the website in your browser:

- Open `index.html` or `games.html` directly in a modern web browser (Chrome, Firefox, Edge, Safari).
- You can double-click the file or right-click and choose "Open with" your browser.

4. The games should load and function without any server setup since this is a static website.

## GitHub Pages Deployment

The website is deployed on GitHub Pages using the `Game` folder as the root.

- The URL for the live site will be:

```
https://sumitrao9.github.io/MVP-KID-GAME/Game/
```

- You can access the games hub at:

```
https://sumitrao9.github.io/MVP-KID-GAME/Game/games.html
```

- The Color Match game is accessible at:

```
https://sumitrao9.github.io/MVP-KID-GAME/Game/index.html
```

## Notes

- Ensure all files and folders in the `Game` directory are pushed to the GitHub repository.
- The site uses relative paths, so it works correctly when served from GitHub Pages.
- For any updates, commit and push changes to the repository, and GitHub Pages will update the site automatically.

## Troubleshooting

- If the site does not load correctly, check that all files are present in the repository.
- Clear your browser cache or try a different browser.
- Verify the GitHub Pages settings in the repository settings.

Enjoy the Kidex games!
